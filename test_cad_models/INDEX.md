# SpatialForge - 50 2D CAD Test Dataset

A comprehensive test suite of 50 mechanical 2D CAD technical drawings (.dxf) and high-resolution blueprints (.png).

### Usage with SpatialForge
Drag and drop any `.dxf` or `.png` file directly onto the SpatialForge intake dropzone at `http://127.0.0.1:3000/` or `http://127.0.0.1:8085/` to reconstruct the 3D solid model.
